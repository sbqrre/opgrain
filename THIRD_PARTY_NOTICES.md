# Upstream JSON0

The JSON0 and text0 rules in this library are based on
[ottypes/json0 at 83222f417762be0e8672adb16657f0b8ba514d0d](https://github.com/ottypes/json0/tree/83222f417762be0e8672adb16657f0b8ba514d0d),
the Git commit for npm `ot-json0@1.1.0`.

Copyright 2011 ottypes library contributors. Jeremy Apthorp wrote the original
JSON type. Joseph Gentle and the ottypes contributors maintained it.

The [upstream README](https://github.com/ottypes/json0/blob/83222f417762be0e8672adb16657f0b8ba514d0d/README.md#license)
declares MIT for contributed code. The upstream npm manifest labels the package
ISC. Both upstream references are retained here. See [LICENSE](LICENSE) for the
MIT license and the upstream copyright notice.

The locked Node test tools are development dependencies. Their license metadata
is recorded in [the test lock file](test/oracle/package-lock.json). The MoonBit
library has no Node runtime dependency.
